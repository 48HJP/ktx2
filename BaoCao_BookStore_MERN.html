2. CÂU 1: CƠ SỞ DỮ LIỆU MONGODB & MODEL

Database sử dụng: BookStoreDB, collection: books.

models/Book.js
const mongoose = require('mongoose'); const bookSchema = new mongoose.Schema({ title: { type: String, required: [true, 'Tên sách không được để trống'], trim: true }, author: { type: String, required: [true, 'Tác giả không được để trống'], trim: true }, price: { type: Number, required: [true, 'Giá tiền không được để trống'], min: [0, 'Giá tiền không được là số âm'] }, isPublished: { type: Boolean, default: true } }, { timestamps: true // Tự động ghi nhận createdAt và updatedAt }); module.exports = mongoose.model('Book', bookSchema);

Giải thích Model: Schema định nghĩa đầy đủ 4 trường theo đúng yêu cầu đề bài: title, author, price đều bắt buộc (required: true) và isPublished mặc định là true. Đã seed thành công 3 cuốn sách mẫu.

3. CÂU 2: XÂY DỰNG RESTFUL API (EXPRESSJS)

Triển khai 2 API endpoints chính tại /api/books:

routes/bookRoutes.js
const express = require('express'); const router = express.Router(); const Book = require('../models/Book'); // 1. GET /api/books — Lấy danh sách toàn bộ sách (sắp xếp mới nhất lên đầu) router.get('/', async (req, res) => { try { const books = await Book.find().sort({ createdAt: -1 }); res.status(200).json(books); } catch (error) { res.status(500).json({ message: 'Lỗi server khi lấy danh sách sách', error: error.message }); } }); // 2. POST /api/books — Thêm sách mới với validation dữ liệu router.post('/', async (req, res) => { try { const { title, author, price, isPublished } = req.body; // Validation kiểm tra tính đầy đủ của trường bắt buộc if (!title || !author || price === undefined || price === null || price === '') { return res.status(400).json({ message: 'Vui lòng cung cấp đầy đủ title, author và price' }); } const newBook = new Book({ title: title.trim(), author: author.trim(), price: Number(price), isPublished: isPublished !== undefined ? isPublished : true }); const savedBook = await newBook.save(); res.status(201).json(savedBook); // Trả về status 201 Created } catch (error) { res.status(400).json({ message: 'Lỗi khi tạo sách', error: error.message }); } }); module.exports = router;

Giải thích Logic API:

  • GET /api/books: Sử dụng Book.find().sort({ createdAt: -1 }) để truy xuất toàn bộ documents từ MongoDB, sắp xếp theo thời gian mới nhất và phản hồi với mã trạng thái 200 OK.
  • POST /api/books: Đọc dữ liệu từ req.body, kiểm tra dữ liệu bắt buộc (trả về 400 Bad Request nếu thiếu hoặc sai định dạng), sau đó dùng new Book().save() lưu vào CSDL và trả về document vừa tạo với mã 201 Created.
